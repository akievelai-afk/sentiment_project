# 中文电商评论情感分析项目

## 项目简介

这是一个面向AI训练师入门实战的完整项目。你将完整体验**数据获取 - 数据清洗 - 数据标注 - 模型训练 - 效果评估 - Prompt优化**的全流程。

做完这个项目，你可以在简历上写：
> "独立完成中文电商评论情感分析项目，涵盖数据清洗、标注、模型微调及效果评估全流程。"

## 项目结构

```
sentiment_project/
scripts/               # Python脚本（按编号顺序执行）
data/                  # 数据文件夹
output/                # 输出结果（模型、图表、报告）
```

## 执行顺序

按编号顺序运行脚本，每个脚本都有详细中文注释。

你将学到：
1. 用Python从Hugging Face下载真实中文数据集
2. 用Pandas做数据探索和清洗 -- AI训练师的日常工作
3. 理解数据标注的流程和标准
4. 用BERT模型做文本分类微调 -- 行业主流做法
5. 用评估指标判断模型好坏
6. 掌握Prompt Engineering的基本方法
